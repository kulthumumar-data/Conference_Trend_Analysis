Critical Flaws to Flag for the Society

Here are the core data quality issues to be noted:

  1. Inconsistent Field Taxonomy (The Naming Trap)

• The Issue: The form layout changed though the data dictionary helped. For example, changing residence (provinces) to region_of_residence (broad territories) • The Impact: Breaks multi-year programming scripts. It forces an analyst to do manual re-mapping in Python instead of generating instant automated charts.

  1. Structural Column Splitting (One-Hot Encoding Mismatch)

• The Issue: The 2025 form collected gender as a clean text string drop-down, while 2026 split gender into completely separate binary check-box columns (man, woman). • The Impact: Increases database bloat and introduces user submission errors. As seen in the earlier analysis, this setup created an edge case where users could choose both or leave both blank, resulting in 2.5% "unspecified" records in 2026.

Recommendations for Future Forms

  1. Enforce Strict Dropdowns: Never use free-form or text-entry fields for categorical metrics like discipline or age. Use immutable dropdown elements.
  2. Unify the Core Schema: Lock down a permanent "Core Registration Data Schema" (Age, Gender, Black Identity, Career, Discipline, Province) that cannot be changed or renamed by future conference committees.
  3. Mandate Responses: Make core demographic fields mandatory on the web-portal interface to eliminate the rise of "No response" gaps.
